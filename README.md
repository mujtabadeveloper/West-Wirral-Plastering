# West Wirral Plastering

Responsive static website with animations and WhatsApp enquiries.

## GitHub
Extract this ZIP and upload its contents to your repository. Keep index.html and assets at the repository root.

## Vercel
Import the GitHub repository. Choose Other as framework. Leave build command empty and use . as output directory.

## GitHub Pages
In Settings > Pages, deploy from main branch and / (root).

The enquiry form opens WhatsApp with a prepared message. No backend is required.
